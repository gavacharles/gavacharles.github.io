Concurrent Delay ML

Construction Law Machine Learning
Code and data on GitHub ↗

The code, data and full documentation are on GitHub. Last updated 2026-11-20.

The question

When owner and contractor delays overlap, can a model of the programme decide who is responsible under different legal rules?

What's inside
  • Synthetic critical-path programmes with simulated owner and contractor risk events
  • Machine-learning classifiers that label concurrency, and an explainable liability-apportionment model
  • A newer causal programme model that applies legal attribution rules (on a development branch)
Why it matters

Concurrent delay is one of the most contested issues in construction claims; making the reasoning explicit and testable helps parties and tribunals.
